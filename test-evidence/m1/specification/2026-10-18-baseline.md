## Agent Skills specification

来源：<https://agentskills.io/specification>

结论：

- Skill 目录至少包含一个 `SKILL.md`；`scripts/`、`references/`、`assets/` 为可选约定目录。
- `SKILL.md` 必须包含 YAML frontmatter 和 Markdown 正文。
- `name` 与 `description` 是必填字段；名称必须与父目录一致，只能使用小写字母、数字和连字符，最长 64 个字符。
- `description` 最长 1024 个字符，应同时描述能力和触发时机。
- references 应使用相对 Skill 根目录的一层引用；资源按需加载。

仓库结论：当前 `skills/brand-visual-designer/SKILL.md` 的名称、父目录和必填 frontmatter 满足上述静态约束。仍需通过目标 Agent 的实际发现测试关闭 M1-02/M1-03。

## OpenAI Skills / Codex

来源：

- <https://developers.openai.com/api/docs/guides/tools-skills>
- <https://developers.openai.com/blog/eval-skills>

结论：

- OpenAI 官方文档声明 Skills 兼容开放 Agent Skills 标准。
- 发现阶段使用 Skill 的名称和描述，激活后读取完整 `SKILL.md`，支持按需引用 references、scripts 和 assets。
- 官方 Codex 示例给出仓库级 `.codex/skills/<name>/SKILL.md` 和用户级 `~/.codex/skills/<name>/SKILL.md`。
- 本机 `codex-cli 0.163.0` 已安装；本文件只记录文档核查，尚未把“发现/执行通过”标记为已验证。

## Node.js 与图像依赖运行时

来源：

- Node.js 发布状态：<https://nodejs.org/en/about/previous-releases>
- Sharp 安装要求：<https://sharp.pixelplumbing.com/install/>
- Playwright 系统要求：<https://playwright.dev/docs/intro>

结论：

- Node.js 24 当前处于 LTS；选择 Node.js 24 作为首要开发和 CI 基线。
- Playwright 当前支持最新的 Node.js 22、24、26 系列。
- Sharp 当前要求 Node-API v9 兼容运行时，例如 Node.js >=20.9.0；pnpm 8+ 有官方跨平台安装说明。
- M1 暂不安装 Sharp 或 Playwright；只锁定与后续 M3 兼容的 Node 主版本，实际引入时再次核查并保存版本证据。
