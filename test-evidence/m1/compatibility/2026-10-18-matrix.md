## 项目级安装生命周期

对 `codex`、`claude-code`、`cursor`、`gemini-cli`、`opencode` 逐一运行：

```text
brand-visual skill install --agent <id> --scope project --json
brand-visual skill update --agent <id> --scope project --json
brand-visual skill uninstall --agent <id> --scope project --json
```

结果：

- 五个平台安装均返回单行有效 CLI JSON，状态为 `installed`，同一源哈希一致。
- 源 reference 变化后，五个平台均检测为 `update_available` 并安全更新到最终哈希。
- 五个平台卸载均返回 `not_installed`；只删除了安装器拥有且逐文件哈希匹配的 Skill 目录。
- 自动化测试覆盖重复安装幂等、非拥有目录冲突、额外/修改文件拒绝更新与卸载、dry-run、用户作用域路径。
